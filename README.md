# Misión 4 - Programación web

Una app React con un formulario serio (React Hook Form + Zod) y datos remotos con TanStack Query: registro + listado, con validación en cliente y peticiones bien gestionadas.

## Uso de IA

Dos prompts reales que me ayudaron a entender el funcionamiento de algunas funciones.

- `como valido el grado para que este en ese enum` me ayudo a validar campos que dependenden de un array, como es el caso de los grados y tipos.

- `para grado lo pondria como string pero haria una validacion con regex` yo habia pensado validar los grados con regex pero la IA me dijo que seria mas complicado que declarar un array.
